# Product Overview

Pictia is a React Native mobile application that helps users organize and backup their Google Photos library through an intuitive swipe-based interface. The app connects to Google Photos Library API to allow users to quickly sort through their photos by swiping left (delete) or right (keep), with scheduled backup functionality to maintain organized photo collections.

## Core Features

- **Swipe Organization**: Bumble-like interface for quickly sorting photos (swipe left to delete, right to keep)
- **Google Photos Integration**: Full integration with Google Photos Library API for reading and managing photo collections
- **Automated Backup**: Scheduled backup system with weekly/monthly options and push notifications
- **Undo Functionality**: Time-limited undo for accidental swipes
- **Cross-Platform**: Native iOS and Android support via React Native and Expo

## Target Users

Users with large Google Photos libraries who want a fast, intuitive way to organize and clean up their photo collections while maintaining automated backup workflows.
